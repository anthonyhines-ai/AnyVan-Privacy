SAR Data Extract · Privacy & Compliance

📋 Overview

The SAR Data Extract dashboard pulls all personal data held about an AnyVan customer across 12 data sources, supporting GDPR Subject Access Requests (Article 15) and Data Portability (Article 20).

👤 Owner

Anthony Hines-Yarde · Privacy & Compliance
Live · v1

🔍 How to Use

  • Enter the customer's email address (required) — this drives lookups across all email-indexed tables.
  • Optionally enter a phone number — this enables Twilio call, SMS, and transcript lookups. All formats accepted (07xxx, +44xxx, 44xxx).
  • Click Extract SAR to run all 12 queries in parallel.
  • Use Export Full SAR (JSON) for a complete GDPR-portable data package.
  • Use per-tab Export CSV for individual data sources.

🗄 Data Sources

Customer Profile (DIM_USER_CUSTOMER) ▾
Name, email, phone, country, language, consent flags, login history. Matched by email.
Listings (LISTING) ▾
All customer listings — title, status, dates, bids, feedback. Linked via USER_ID from profile. Max 500 rows.
Payments (PAYMENT) ▾
AnyVan payment records — amount, method, status, transaction IDs. Linked via USER_ID. Max 1000 rows.
Stripe Payments (UK/ES/FR) ▾
Stripe payment intents across all 3 territories. Matched by RECEIPT_EMAIL. Max 1000 rows.
Twilio Calls ▾
Call records — direction, duration, timestamps. Matched by phone suffix (last 10 digits). Requires phone input.
Twilio SMS ▾
SMS message records — direction, body, status. Matched by phone suffix. Requires phone input.
Call Transcripts ▾
Speech-to-text transcripts segmented by speaker. Matched by phone digits. Requires phone input. Max 5000 segments.
Email Events — HubSpot ▾
HubSpot email event log — sends, opens, clicks, bounces. Matched by email. Note: Mandrill transactional emails are not yet in Snowflake.
Freshdesk Tickets ▾
Support tickets — subject, description, status, priority. Matched by REQUESTER_EMAIL. Max 1000 rows.
Listing Communications ▾
System communications tied to listings — emails, SMS, notifications. Linked via USER_ID → listings. Max 2000 rows.
Listing Feedback ▾
Customer feedback and ratings on listings. Linked via USER_ID → listings.
Pre-Listing Emails ▾
Emails sent before listing activation — templates, timestamps. Matched by email.

⚠️ Known Gaps

  • Mandrill transactional emails — not currently in Snowflake. Only HubSpot marketing/CRM email events are available.
  • Twilio Conversations (WhatsApp/chat) — not yet included. TWILIO_CONVERSATION_MESSAGE lacks a direct customer phone join column.
